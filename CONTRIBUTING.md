# Как помочь проекту

Спасибо, что заглянули! Общение, комментарии в коде и описания PR —
на русском; идентификаторы в коде — на английском. Если по-русски
писать трудно, пишите по-английски — пойму.

## Что можно сделать

- **Сообщить об ошибке** — через [issue](../../issues/new/choose).
  Лучше всего приложить SVG, на котором видно проблему, и версию
  программы.
- **Добавить перевод** — самый простой вклад: один JSON-файл без кода.
  Инструкция — в [`docs/TRANSLATIONS.md`](docs/TRANSLATIONS.md).
- **Предложить идею** — тоже issue. Планы лежат в
  [`docs/ROADMAP.md`](docs/ROADMAP.md), возможно, это уже там.
- **Исправить код** — сначала откройте issue или напишите в нём, что
  беретесь: так не придётся переделывать, если решение не подойдёт.

## Принципы проекта

Они же в [`CLAUDE.md`](CLAUDE.md). Главные:

- приложение **не обращается к сети**: ни телеметрии, ни обновлений, ни
  CDN; все ресурсы внутри сборки;
- SVG разбирает только `usvg`, без собственного парсера;
- ядро не форматирует тексты для людей — оно отдаёт коды замечаний,
  перевод делают интерфейс и CLI;
- значения требований Telegram берутся из официальной документации и
  закреплены тестами;
- любое изменение конвертера проверяется попиксельным тестом
  (`render/tests/pixel.rs`); найденный случай — новая фикстура;
- в интерфейсе цвета, шрифты и отступы — только через переменные из
  `app/src/styles/tokens.css`.

## Как отправить изменение

1. Сделайте форк и ветку от `main`. В `main` напрямую не коммитим.
2. Перед отправкой выполните (сборка — в [`docs/BUILD.md`](docs/BUILD.md)):

   ```sh
   cargo fmt --all
   cargo clippy --workspace --all-targets -- -D warnings
   cargo test --workspace
   cd app && npm run build
   ```

3. Если поведение для пользователя меняется — допишите
   [`docs/SPEC.md`](docs/SPEC.md).
4. Откройте pull request и заполните шаблон. Проверки на GitHub
   (Windows, Linux, «Зависимости») должны быть зелёными.

Вклад принимается на условиях лицензии проекта — [MIT](LICENSE).
