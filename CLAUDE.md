# Договорённости по проекту svg2tgs

## Общение и документы
- Общение с владельцем, комментарии в коде, документация, сообщения
  коммитов и описания PR — на русском.
- Идентификаторы в коде — на английском.

## Процесс
- Каждый этап — отдельная ветка `claude/<этап>` и pull request.
  В `main` напрямую не коммитим.
- Перед PR: `cargo fmt --all`, `cargo clippy --workspace --all-targets`
  без предупреждений, `cargo test --workspace`, `npm run build` в `app/`.
- Публичные изменения поведения — с записью в `docs/SPEC.md`.

## Принципы
- Приложение не обращается к сети: никакой телеметрии, CDN, проверок
  обновлений. Все ресурсы интерфейса — внутри сборки.
  Единственное исключение — выгрузка в Telegram (крейт `publish`):
  только к `api.telegram.org`, только по явному действию пользователя,
  в приложении — только после включения в «Настройках». Сетевой код —
  только в этом крейте.
- Разбор SVG — только через usvg, без собственного парсера.
- Ядро не форматирует тексты для людей: замечания — коды с параметрами
  (`core/src/report.rs`), перевод делают интерфейс и CLI.
- Значения требований Telegram (канвас, fps, длительность, размер) берутся
  из официальной документации и закреплены тестами, не «по памяти».
- Любое изменение конвертера проверяется попиксельным тестом
  (`render/tests/pixel.rs`), крупные — ещё и прогоном больших наборов
  (`render/examples/corpus.rs`). Новый найденный случай — новая фикстура.
- Особенности rlottie обходятся в конвертере и подтверждаются тестом,
  который без обхода падает. Эталон для сравнения — resvg, не cairo.

## Интерфейс
- Цвета, шрифты, отступы, радиусы — только через переменные
  из `app/src/styles/tokens.css`. Макет подключает копию этого файла.
- Один компонент макета — один компонент React.
- Интерфейс должен открываться в обычном браузере (`npm run dev`)
  с тестовыми данными из `app/src/backend.ts` — для сверки с макетом.
- Источник правды по внешнему виду — макет в Claude Design (`docs/DESIGN.md`).

## Как ведём работу
- Задачи ставит владелец в чате. Этап делается целиком: код, тесты,
  документы, проверки из «Процесса», затем ветка и PR. Ссылку на PR —
  в конце работы.
- Проверки GitHub (Linux, Windows, «Зависимости», CodeQL) **не ждать
  в фоне** — владелец смотрит их сам. Состояние проверок — одним запросом
  и только по просьбе.
- Слияние (squash) и выпуск (Actions → «Выпуск») делает владелец.
  Черновик выпуска пересобирается тем же «Выпуском», пока не опубликован.
- Новая сессия — на каждый этап или версию. Что сделано и что дальше —
  в `docs/ROADMAP.md` и в разделе «Текущее» ниже; обновлять их в PR,
  которым этап заканчивается.
- Ответы — подробные по сути работы: что сделано, что проверено, что
  нужно от владельца. Без пересказа шагов.

## Макет (Claude Design)
- Ссылку на макет владелец даёт в первом сообщении сессии (см. также
  `docs/DESIGN.md`). Страницы: «Main» — экраны и компоненты, «Выгрузка
  в Telegram» — путь подключения бота, «Page 2» — черновики владельца.
- Читать **только экраны, которые назвал владелец**, и `canvas.json` —
  только если меняется раскладка. Если задача требует других экранов,
  сначала сказать об этом и спросить.
- Владелец правит макет параллельно: перед правкой перечитать файл,
  `canvas.json` перечитать прямо перед отправкой.
- Снимки экрана — только когда меняется внешний вид, и только
  затронутых экранов.
- Правки макета копятся списком; по «применяй» переносятся в код новой
  версией. Новое в коде (состояние, кнопка) — дорисовать в макете.

## Окружение сессии
- `gh` — только REST (`gh api repos/Ax1oMgg/svg2tgs/...`): GraphQL
  недоступен, PR создаётся через `gh api .../pulls -f title=... -f head=...`.
- Разделы Security (тревоги Dependabot и CodeQL) закрыты для API —
  просить у владельца текст или снимок тревоги.
- `api.telegram.org` из среды недоступен: выгрузку проверять заглушкой
  (`publish/tests/fake.rs`) и локальным HTTP-сервером
  (`publish/src/http.rs`), на настоящем боте проверяет владелец.
- Диск ограничен: при нехватке чистить `target/debug/{deps,incremental,examples}`.
- Интерфейс в браузере: `npx vite --port 5179` в `app/`, адрес с `?demo` —
  тестовые файлы; снимки — Playwright (для видимых полос прокрутки —
  `ignoreDefaultArgs: ['--hide-scrollbars']`). Не завершать процессы
  `pkill -f` с шаблоном, который совпадает с самой командой.
- Большие наборы SVG для `render/examples/corpus.rs` (флаги, Lucide,
  OpenMoji, Simple Icons, Twemoji) скачиваются из npm; при обновлении
  usvg/resvg или правке конвертера — прогон на `main` и на ветке
  и пофайловое сравнение `all.csv`.

## Зависимости и безопасность
- usvg и resvg обновляются только вместе (группа в `.github/dependabot.yml`).
  Плагины Tauri — Rust- и JS-часть вместе.
- glib 0.18 (GHSA-wrw7-89jp-8q8g) приходит из GTK 3-стека Tauri 2 (Linux),
  `VariantStrIter` не вызывается; тревога закрыта до перехода Tauri на GTK 4.
  `zvariant`, `zbus_names` (unmaintained) — через `zbus`, информационно.
- Ложные тревоги CodeQL (например, «логирование» имени бота) закрываются
  с объяснением; переименовывать код ради сканера не надо.
- Выгрузка в Telegram: токен — только в системном хранилище паролей;
  проверка «выгрузка включена» — в Rust (`telegram.rs`, `Access`).
