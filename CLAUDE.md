# Договорённости по проекту svg2tgs

## Общение и документы
- Общение с владельцем, комментарии в коде, документация, сообщения
  коммитов и описания PR — на русском.
- Идентификаторы в коде — на английском.

## Процесс
- Каждый этап — отдельная ветка `claude/<этап>` и pull request.
  В `main` напрямую не коммитим.
- Перед PR: `cargo fmt --all`, `cargo clippy --workspace --all-targets`
  без предупреждений, `cargo test --workspace`, `npm run build` в `app/`.
- Публичные изменения поведения — с записью в `docs/SPEC.md`.

## Принципы
- Приложение не обращается к сети: никакой телеметрии, CDN, проверок
  обновлений. Все ресурсы интерфейса — внутри сборки.
- Разбор SVG — только через usvg, без собственного парсера.
- Ядро не форматирует тексты для людей: замечания — коды с параметрами
  (`core/src/report.rs`), перевод делают интерфейс и CLI.
- Значения требований Telegram (канвас, fps, длительность, размер) берутся
  из официальной документации и закреплены тестами, не «по памяти».
- Любое изменение конвертера проверяется попиксельным тестом
  (`render/tests/pixel.rs`), крупные — ещё и прогоном больших наборов
  (`render/examples/corpus.rs`). Новый найденный случай — новая фикстура.
- Особенности rlottie обходятся в конвертере и подтверждаются тестом,
  который без обхода падает. Эталон для сравнения — resvg, не cairo.

## Интерфейс
- Цвета, шрифты, отступы, радиусы — только через переменные
  из `app/src/styles/tokens.css`. Имена соответствуют переменным в Figma.
- Один компонент Figma — один компонент React.
- Интерфейс должен открываться в обычном браузере (`npm run dev`)
  с тестовыми данными из `app/src/backend.ts` — это нужно для захвата в Figma.
- Источник правды по внешнему виду — макет в Figma.
