# Безопасность

## Сообщить об уязвимости

**Не создавайте публичный issue** об уязвимости. Напишите
приватно: на странице репозитория → вкладка **Security** →
**Report a vulnerability**. Сообщение увидит только владелец проекта.

Указать: версию svg2tgs, систему, описание проблемы и способ
воспроизведения (файл SVG или команда). Исправление выходит в ближайшей
версии; автор сообщения указывается в описании выпуска, если не против.

## Что считается уязвимостью

- выход за пределы выбранных папок при чтении и записи файлов;
- запуск постороннего кода из SVG, настроек (`.json`) или имён файлов;
- любые обращения программы к сети — приложение не должно ничего
  отправлять и скачивать;
- слабые места в сборке и выпуске (Actions, зависимости).

Ошибки конвертации (стикер выглядит не так, как SVG) — это обычные
[issue](../../issues/new/choose), не уязвимости.

## Поддерживаемые версии

Исправления выходят только для последней версии на странице
[Releases](../../releases).

## Как устроена защита

Приложение работает полностью локально, интерфейс не загружает ничего
извне (строгая политика CSP), права Tauri сведены к минимуму, SVG
разбирает только `usvg`. Зависимости проверяются еженедельно
(`cargo audit`, `npm audit`) и обновляются через Dependabot.
