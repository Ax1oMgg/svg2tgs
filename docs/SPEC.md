# svg2tgs — описание функционала

Настольное приложение для Windows, macOS и Linux, которое превращает SVG
в стикеры и эмодзи Telegram (формат TGS). Работает полностью локально:
не обращается к сети, не собирает телеметрию, не проверяет обновления.

Отметки: **[MVP]** — первая версия, **[позже]** — после неё.

## Сценарий

Открыл программу → перетащил SVG → увидел превью и замечания → нажал
«Экспортировать». Настройки по умолчанию подобраны под Telegram, большинству
пользователей не нужно ничего трогать, кроме выбора пресета.

## 1. Добавление файлов
- **[MVP]** Перетаскивание файлов и папок в окно.
- **[MVP]** Над списком — кнопка «Добавить» (файлы) и прижатая к ней
  кнопка-папка (папка целиком); на пустом экране — «Добавить файлы»,
  «Добавить папку» и галочка «включая вложенные».
- **[MVP]** Вставка SVG-кода из буфера (Ctrl+V / ⌘V), например после
  «Copy as SVG» в Figma.
- **[MVP]** Повторно добавленный файл не дублируется.

## 2. Список файлов
- **[MVP]** Миниатюра, имя, размер итогового `.tgs`, статус:
  ✓ готово · ⚠ есть замечания · ✗ ошибка.
- **[MVP]** Длинное имя обрезается посередине: последние 16 символов
  видны всегда (если в пределах 4 символов левее есть пробел, `_` или `-`,
  хвост начинается с него); полное имя — во всплывающей подсказке и над превью.
- **[MVP]** Внизу списка — сводка, а во время конвертации — полоска
  прогресса, процент и три числа: без замечаний, с замечаниями, с ошибкой.
- **[MVP]** Конвертация сразу при добавлении, в фоне и параллельно;
  интерфейс не подвисает.
- **[MVP]** Удаление из списка, «Очистить всё», фильтр «только проблемные».
- **[позже]** Сортировка по имени, размеру, статусу.

## 3. Превью
- **[MVP]** Две панели: исходный SVG и результат TGS, отрисованный тем же
  движком, что у Telegram (rlottie).
- **[MVP]** Фон: светлый чат, тёмный чат, шахматка.
- **[MVP]** Масштаб: «как в чате» (реальный размер стикера или эмодзи
  в строке текста) и крупно.
- **[позже]** Режим «разница»: подсветка мест, где результат отличается.

## 4. Замечания и ошибки
- **[MVP]** Для каждого файла понятный список изменений с причиной, например:
  «Размытие не поддерживается в Telegram и было убрано», «Текст переведён
  в кривые», «Файл 71 КБ при лимите 64 КБ — включите автоподгонку».
- **[MVP]** Ошибки без технических подробностей: «Файл повреждён или это не SVG».
- **[MVP]** Текст переводится в кривые установленными шрифтами. Если
  указанного шрифта нет, берётся похожий установленный (без засечек,
  с засечками, моноширинный); если шрифтов нет совсем, текст убирается
  с замечанием «текст не удалось перевести в кривые».
- Ядро возвращает замечания как коды с параметрами (`core/src/report.rs`),
  интерфейс и CLI переводят их на язык пользователя.

## 5. Настройки конвертации
Правая колонка — «Панель экспорта». Переключатель «Настройки экспорта:
всех файлов / этого файла» выбирает, что правится: общие настройки или
свои настройки выбранного файла. Файл со своими настройками помечен
в списке («свои настройки»); при смене общих он не пересчитывается.
Возврат на «всех файлов» снимает свои настройки файла.

| Настройка | Значения | По умолчанию |
|---|---|---|
| **[MVP]** Пресет | Стикер, Эмодзи | Стикер |
| **[MVP]** «Объект»: отступ от края | 0–20 %, поле и ползунок | 0 % |
| **[MVP]** «Объект»: обводка вокруг рисунка | выкл.; толщина 1–64 px из 512, цвет | выкл.; 12 px, белая |
| **[MVP]** «Фон»: скругление углов | 0–256 px из 512, поле и ползунок | 0 |
| **[MVP]** «Фон»: заливка | выкл.; цвет | выкл. (прозрачный) |
| **[MVP]** «Фон»: обводка фона | выкл.; толщина 1–64 px, цвет | выкл.; 12 px |
| **[MVP]** Вписывание | Целиком, С обрезкой | Целиком |
| **[MVP]** Оптимизация размера | Авто, Без потерь, Вручную | Авто |
| **[позже]** Расширенные | fps, длительность, канвас вне пресета | из пресета |

Пресет задаёт канвас, fps, длительность и лимит размера по требованиям
Telegram (https://core.telegram.org/stickers, сверено 24.10.2026):
канвас 512×512, 60 кадров/с, не дольше 3 с, файл до 64 КБ — одинаково для
стикеров и анимированных эмодзи. Если расширенные настройки нарушают
требования, файл всё равно создаётся, но с замечанием.

### Соответствие правилам Telegram
- Telegram запрещает в TGS маски, градиентные обводки, merge paths, repeater,
  текстовые и картиночные слои, сплошные слои, 3D, эффекты. Конвертер их
  не выдаёт: `clipPath` применяется геометрически, градиентная обводка
  становится залитым контуром.
- Объекты не выходят за канвас: всё, что вылезает больше чем на 1 px,
  обрезается (например, в режиме «Заполнить с обрезкой»).

Разделы «Объект», «Фон» и «Дополнительно» раскрываются по щелчку и по
умолчанию закрыты. Выбор из 2–3 вариантов — сегментный переключатель,
а не выпадающий список.

### Фон
- Заливка и обводка фона — квадрат на весь канвас со скруглёнными углами.
- Обводка фона лежит внутри канваса: внешний край совпадает с краем фона,
  внутренний скруглён радиусом «скругление − толщина». Порядок слоёв
  сверху вниз: рисунок, обводка рисунка, обводка фона, заливка фона.

### Обводка вокруг рисунка
- Как у вырезанных стикеров: силуэт всех видимых заливок и обводок
  расширяется на заданную толщину со скруглёнными углами; дырки внутри
  силуэта заливаются. Слой обводки лежит под рисунком и над фоном.
- Место под обводку вычитается при вписывании: рисунок с обводкой
  помещается в канвас с тем же отступом от края.

### Оптимизация размера
- **Авто** (по умолчанию): контуры упрощаются с отклонением до 0,05 px —
  невидимо. Если файл больше 64 КБ, отклонение и точность чисел
  повышаются ступенями (0,1 → 0,25 → 0,5 → 1 → 1,5 → 2,5 px), пока файл
  не влезет. Пользователь видит замечание с итоговым отклонением; до 0,5 px
  оно справочное, от 0,5 px — предупреждение.
- **Без потерь**: без упрощения, 3 знака после запятой.
- **Ручная точность**: заданное число знаков, упрощение 0,05 px.

### Проверки для эмодзи
- Линии тоньше 12 px на канвасе 512 (≈ полпикселя в строке текста)
  дают предупреждение: в сообщении они почти пропадут. Это оценка
  svg2tgs, а не требование Telegram.

## 6. Экспорт
- **[MVP]** Кнопка «Экспортировать» вверху панели экспорта сохраняет все
  готовые файлы сразу, без промежуточного окна.
- **[MVP]** Папка: по умолчанию «В папку источника» — каждый TGS рядом
  со своим SVG; «Выбрать» задаёт общую папку, «×» возвращает «В папку
  источника». Для SVG из буфера, если общая папка не задана, программа
  спрашивает папку при экспорте.
- **[MVP]** Имя: префикс + имя SVG + суффикс; подпапка внутри папки
  экспорта. Каждое поле включается флажком; по умолчанию все три
  выключены и пустые.
- **[MVP]** Если файл существует — добавляется номер: `heart_tg (2).tgs`.
- **[MVP]** После экспорта — сводка и «Открыть папку», если все файлы
  легли в одну папку.
- **[позже]** Дополнительно `.json` (Lottie без сжатия) для отладки.

## 7. Настройки программы
- **[MVP]** Окно «Настройки» — по кнопке-шестерёнке в верхней панели.
  Название программы — в заголовке окна ОС: «svg2tgs by Чайная Аксиома».
- **[MVP]** Язык (выпадающий список): русский, английский. Тема
  (переключатель): как в системе, светлая, тёмная.
- **[MVP]** Выбор применяется кнопкой «Готово» (активна, когда что-то
  изменено); «×», Esc или щелчок мимо окна закрывают его без изменений.
- **[MVP]** «О программе»: версия, проект «Чайная Аксиома», автор,
  лицензия и ссылка «Страница проекта» (текстом, открывается в браузере).
- **[MVP]** Запоминание последних настроек и параметров экспорта.

## 8. Командная строка
- **[MVP]** `svg2tgs` — тот же движок для пакетной обработки и скриптов.
  Флаги: `-o` папка, `--preset sticker|emoji`, `-r` вложенные папки,
  `--on-conflict number|overwrite|skip`, `--padding` (%),
  `--fit contain|cover`, `--bg #rrggbb`, `--bg-radius 64`,
  `--bg-border 12[:#rrggbb]`, `--outline 12[:#rrggbb]`,
  `--optimize auto|lossless|0–6`,
  `--fps`, `--duration`, `--json` (отчёт для скриптов), `-j` (потоки).
  В конце — сводка: сколько с замечаниями, пропущено, больше лимита.
- Одинаковые имена из разных папок не затирают друг друга: второй файл
  получает номер `icon_1.tgs`.
- Файлы обрабатываются параллельно, вывод — в порядке входных файлов.
- Коды выхода: 0 — всё сконвертировано, 1 — нечего обрабатывать,
  2 — часть файлов с ошибкой.
- В консоли Windows включается UTF-8, чтобы кириллица и значки
  отображались и в старом cmd.exe.

## 9. Поставка
- Windows: два установщика, ставятся без прав администратора —
  - **обычный**: если в системе нет WebView2, установщик скачает его;
  - **офлайн**: WebView2 вшит в установщик (≈ +130 МБ), установка без интернета.
- macOS 10.15+: `.dmg`, один файл для Intel и Apple Silicon.
- Linux: `.deb` и `.AppImage`.
- Командная строка — отдельные архивы для каждой ОС.
- Установщики собирает GitHub Actions по метке версии, к релизу
  прикладываются контрольные суммы SHA-256 (`docs/RELEASE.md`).
- Пока без цифровой подписи: при первом запуске Windows и macOS
  предупреждают о неизвестном издателе (как пройти — в README).
- Внутри установки — `LICENSE.txt` и `THIRD_PARTY_NOTICES.md`.
