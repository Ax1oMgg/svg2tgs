# Командная строка

Архив `svg2tgs-cli_…` для своей системы — на странице
[Releases](https://github.com/Ax1oMgg/svg2tgs/releases/latest).
Из исходников: `cargo run --release -p svg2tgs-cli -- …`.

```sh
svg2tgs папка_с_svg -o папка_для_tgs
svg2tgs logo.png --remove-bg          # картинка: трассировка в контуры
```

| Параметр | Что делает |
|---|---|
| `--preset sticker\|emoji` | стикер или эмодзи |
| `-r` | вложенные папки |
| `--on-conflict` | что делать, если файл уже есть |
| `--padding`, `--bounds`, `--fit`, `--scale`, `--position` | размещение |
| `--flip-h`, `--flip-v`, `--rotate`, `--aspect`, `--crop` | трансформация |
| `--bg`, `--bg-radius`, `--bg-border`, `--no-bg-clip`, `--outline` | фон и обводка |
| `--grid 8x5\|auto` | нарезка на сетку эмодзи |
| `--trace auto\|drawing\|pixel\|photo` | способ трассировки картинок (PNG, JPEG, WebP); `auto` — по картинке |
| `--colors N`, `--details 0–100` | число цветов, мелкие детали (по умолчанию — по способу) |
| `--remove-bg`, `--no-gradients` | убрать сплошной фон по углам; переходы полосами, без градиентов |
| `--trace-scale K` | отладка: пикселей трассировки на пиксель канваса |
| `--options файл.json` | настройки из файла (экспорт из приложения) |
| `--optimize`, `--fps`, `--duration` | файл и анимация |
| `-j`, `--jobs` | число потоков |
| `--json` | отчёт для скриптов |

Подробно — `svg2tgs --help`.

## Выгрузка в Telegram

Готовые `.tgs` — в новый набор стикеров или эмодзи через своего бота.
Бота создают у [@BotFather](https://t.me/BotFather) командой `/newbot`,
затем пишут ему `/start` — так программа узнаёт, в чей аккаунт создавать
набор.

```sh
export SVG2TGS_BOT_TOKEN=123456789:AA…   # Windows: set SVG2TGS_BOT_TOKEN=…
svg2tgs publish папка_с_tgs --title "Сердечки" --kind emoji --emoji ❤️
```

| Параметр | Что делает |
|---|---|
| `--title` | название набора (1–64 символа) |
| `--name` | адрес без `_by_<бот>`; по умолчанию — из названия |
| `--kind sticker\|emoji` | набор стикеров или эмодзи |
| `--emoji ❤️,😍` | эмодзи для каждого файла (1–20) |
| `--resume` | дописать в набор после обрыва |
| `--append` | дописать файлы в существующий набор этого бота (адрес — `--name`) |
| `--base N` | при `--append` после обрыва — сколько было в наборе до начала |
| `--thumbnail N\|файл.tgs` | обложка набора: номер файла (с 1) или свой `.tgs` до 32 КБ (только для стикеров) |
| `--user-id` | владелец без `/start` |
| `--json` | итог для скриптов |

Порядок, эмодзи и удаление стикеров уже выгруженного набора — в программе
(«Изменить набор…»): в командной строке на стикеры пришлось бы ссылаться
по номерам.

Программа обращается только к `api.telegram.org` и только в этой команде.
