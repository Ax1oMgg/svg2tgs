# Переводы

Тексты интерфейса лежат в `app/src/locales/` — по файлу на язык:
`ru.json`, `en.json`… Это только данные: объект «ключ → строка», без кода.
Ошибка в переводе может испортить надпись, но не программу: тексты
выводятся как текст (без HTML), адреса ссылок и всё остальное — в коде.

## Как добавить язык

1. Скопируйте `app/src/locales/en.json` в файл с кодом языка:
   `de.json`, `uk.json`, `pt-BR.json` (код языка по BCP 47, регион —
   заглавными).
2. Впишите в `_language` название языка на нём самом: `Deutsch`,
   `Українська`, `Português (Brasil)`.
3. Переведите строки. Слова в фигурных скобках — подстановки (`{n}`,
   `{name}`): их не переводить и не удалять, порядок можно менять.
   `_comment` можно перевести или оставить.
4. Проверьте: в папке `app` выполните `npm run check-locales` (то же
   проверяется при каждой сборке и в PR). Проверка следит, что ключи те же,
   что в `ru.json`, и в каждой строке те же подстановки.
5. Пришлите pull request **только с этим файлом**. Код для нового языка
   менять не нужно: язык появится в «Настройках» сам, а при первом запуске
   включится у тех, у кого он стоит в системе.

Если в эталоне (`ru.json`) появилась новая строка, а в переводе её ещё нет,
проверка подскажет, какой ключ добавить; до тех пор программа покажет
эту строку по-русски.

## Для того, кто проверяет PR с переводом

- В PR изменён только `app/src/locales/<код>.json` — больше ничего.
- Проверки (`npm run build`) зелёные.
- Строки — обычный текст, без ссылок на сторонние сайты и рекламы.
