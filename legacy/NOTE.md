# legacy

Исходный Python-скрипт, с которого начался проект. Не используется
и не поддерживается — лежит для сравнения результатов.

Известные проблемы, из-за которых ядро переписано:
- толщина обводки не масштабируется вместе с рисунком;
- `fill-rule="evenodd"` всегда превращается в nonzero;
- дуги со слитными флагами (`a1 1 0 01 2 2`, вывод SVGO) ломают разбор;
- `opacity` группы не перемножается с вложенными;
- не понимает единицы (`px`), `<use>`, CSS-классы из `<style>`.
