# svg2tgs — конвертер SVG → Telegram TGS

Не требует установки сторонних библиотек — только Python 3 (стандартная библиотека).

## Что поддерживается
- `<path>` (все команды: M/L/H/V/C/S/Q/T/A/Z, включая дуги и сглаженные кривые)
- `<rect>` (в т.ч. со скруглёнными углами rx/ry), `<circle>`, `<ellipse>`, `<polygon>`, `<polyline>`, `<line>`
- Группы `<g>`, вложенность, `transform` (translate/scale/rotate/skewX/skewY/matrix — комбинации)
- `fill`, `stroke`, `stroke-width`, `opacity`, `fill-opacity`, `stroke-opacity`, наследование стилей, атрибут `style="..."`
- Цвета: `#rgb`, `#rrggbb`, `#rrggbbaa`, `rgb()/rgba()`, именованные CSS-цвета
- `viewBox` с автоматическим вписыванием в квадратный канвас (аналог `xMidYMid meet`)

## Чего нет (осознанно, чтобы не выдавать "битый" результат)
- Градиенты, паттерны, фильтры, клип-маски, текст (`<text>`) — при встрече игнорируются на уровне `<defs>/<clipPath>` или заливка падает на чёрный цвет как безопасный фолбэк. Если в ваших эмодзи это используется часто — скажите, добавлю поддержку линейных/радиальных градиентов отдельным шагом.

## Использование

Один файл:
```
python3 svg2tgs.py icon.svg -o icon.tgs
```

Папка (все *.svg внутри → все *.tgs в выходную папку):
```
python3 svg2tgs.py ./svg_folder -o ./tgs_folder
```

По маске:
```
python3 svg2tgs.py "./icons/*.svg" -o ./tgs_folder
```

## Параметры
- `--size N` — сторона канваса (по умолчанию 512; для кастом-эмодзи Telegram часто используют 100)
- `--fps N` — кадров/сек (по умолчанию 60, требование Telegram)
- `--duration S` — длительность анимации в секундах (по умолчанию 1.0; анимация статична по содержимому, но формально имеет длину, т.к. TGS не рассчитан на 0-кадровые ролики)
- `--bg COLOR` — цвет фона (по умолчанию прозрачный)
- `--max-size KB` — порог предупреждения о превышении лимита размера файла (по умолчанию 64 КБ — актуальный лимит Telegram для стикеров/эмодзи)

## Важно перед загрузкой в Telegram
- Итоговый `.tgs` должен быть ≤ 64 КБ (скрипт предупредит, если больше — обычно помогает упростить SVG: меньше узлов на кривых, убрать лишние группы).
- Для кастомных эмодзи Telegram требует конкретный размер канваса (уточните актуальное значение в боте @BotFather/документации, т.к. оно может отличаться для эмодзи и обычных стикеров) — задайте его через `--size`.
- Проверяйте результат перед массовой загрузкой: откройте `.tgs` через любой Lottie-плеер (например lottiefiles.com/preview — переименуйте `.tgs` в `.json`, предварительно распаковав gzip) или через тестового Telegram-бота загрузки стикеров.
